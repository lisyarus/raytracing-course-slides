\frametitle{Описание практики}
\usemintedstyle{solarized-light}
\begin{itemize}
\item В этой практике нужно поддержать четыре типа текстур:
\begin{itemize}
\item 1. Base color texture
\item 2. Normal texture
\item 3. Metallic roughness texture
\item 4. Emissive texture
\end{itemize}
\item Environment maps не требуются, но их очень легко поддержать, и они помогут в тестировании
\end{itemize}
\end{frame}
